## What is Module Federation?

Module Federation is a Webpack 5 feature that enables multiple independent builds to share code and dependencies at runtime. Instead of bundling everything into a single application, you can split your frontend into independent micro frontends that load and share components dynamically.

This repository contains **over 80 working examples** covering everything from basic host/remote patterns to advanced server-side rendering, cross-framework integration, and production deployment strategies.

## Why Module Federation?

Module Federation solves the key challenges of micro frontend architecture:

- **Independent deployability** — each team ships their own application on their own schedule
- **Shared dependencies** — React, design systems, and utilities are loaded once, not duplicated
- **Runtime composition** — applications discover and load each other without a full rebuild
- **Framework agnostic** — React, Vue, Angular, Svelte, and more can all share modules

## Who uses Module Federation?

Module Federation is used in production by Netflix, Amazon, Microsoft, Shopify, PayPal, Adobe, Alibaba, and hundreds of other companies. It's the standard approach for micro frontend architecture with Webpack.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Node.js 16+** — check with `node --version`
- **pnpm** — install with `npm install -g pnpm`

<Note>
  The examples repository uses pnpm workspaces. npm and yarn are not supported at the repo root.
</Note>

## Run the basic-host-remote example

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/module-federation/module-federation-examples.git
    cd module-federation-examples
    ```
  </Step>

  <Step title="Install dependencies">
    Run `pnpm install` from the repository root. pnpm workspaces resolves dependencies for all examples at once.

    ```bash
    pnpm install
    ```
  </Step>

  <Step title="Start the example">
    Navigate into the `basic-host-remote` directory and run `pnpm start`. This builds and serves both applications concurrently.

    ```bash
    cd basic-host-remote
    pnpm start
    ```

    You should see both dev servers start up:

    | App  | Role            | URL                     |
    | ---- | --------------- | ----------------------- |
    | app1 | Host            | http://localhost:3001   |
    | app2 | Remote          | http://localhost:3002   |
  </Step>

  <Step title="Open the host application">
    Open [http://localhost:3001](http://localhost:3001) in your browser. You will see the host application (app1) rendering a `Button` component that was loaded from app2 at runtime.

    You can also open [http://localhost:3002](http://localhost:3002) to confirm app2 runs independently as a standalone application.
  </Step>
</Steps>

## What you're seeing

The host application (`app1`, port 3001) imports `Button` directly from the remote application (`app2`, port 3002) at runtime — no build-time bundling of app2's code into app1.

In `app1/src/routes/page.jsx`, the import looks like a standard ES module import:

```jsx app1/src/routes/page.jsx
import Button from 'app2/Button';

const Index = () => (
  <div className="container-box">
    <h1>Basic Host-Remote</h1>
    <p className="description">
      FEDERATED: <Button />
    </p>
  </div>
);
```

The `Button` component itself lives in `app2/src/components/button.js`:

```js app2/src/components/button.js
import React from 'react';

const Button = () => (
  <button style={{ padding: '10px', background: 'red' }}>App 2 Button!!!!</button>
);

export default Button;
```

At runtime, the browser fetches `http://localhost:3002/static/js/remoteEntry.js` — app2's container manifest — and resolves the `Button` module from there.

## The configuration

Here is what makes federation work in each application.

<CodeGroup>

```js app1/modern.config.js (host)
import appTools, { defineConfig } from '@modern-js/app-tools';
import { ModuleFederationPlugin } from '@module-federation/enhanced/webpack';

export default defineConfig({
  server: {
    port: 3001,
  },
  source: {
    // Generates an async boundary so federated modules can be loaded dynamically
    enableAsyncEntry: true,
  },
  tools: {
    webpack: (config, { appendPlugins }) => {
      delete config.optimization.splitChunks;
      config.output.publicPath = 'auto';

      appendPlugins([
        new ModuleFederationPlugin({
          name: 'app1',
          remotes: {
            // Maps the 'app2' import prefix to the remote container URL
            app2: 'app2@http://localhost:3002/static/js/remoteEntry.js',
          },
          shared: {
            react: { singleton: true },
            'react-dom': { singleton: true },
          },
        }),
      ]);
    },
  },
  plugins: [appTools()],
});
```

```js app2/modern.config.js (remote)
import appTools, { defineConfig } from '@modern-js/app-tools';
import { ModuleFederationPlugin } from '@module-federation/enhanced';

export default defineConfig({
  server: {
    port: 3002,
  },
  source: {
    enableAsyncEntry: true,
  },
  tools: {
    webpack: (config, { appendPlugins }) => {
      delete config.optimization.splitChunks;
      config.output.publicPath = 'auto';

      appendPlugins([
        new ModuleFederationPlugin({
          name: 'app2',
          library: { type: 'window', name: 'app2' },
          filename: 'static/js/remoteEntry.js',
          exposes: {
            // Exposes Button at the path './Button'
            './Button': './src/components/button.js',
          },
          shared: {
            react: { singleton: true },
            'react-dom': { singleton: true },
          },
        }),
      ]);
    },
  },
  plugins: [appTools()],
});
```

</CodeGroup>

<Tip>
  The `shared` config with `singleton: true` ensures both apps use the same React instance, preventing hook errors that occur when multiple React copies are loaded.
</Tip>
